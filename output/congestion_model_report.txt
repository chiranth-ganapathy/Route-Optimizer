HONEST SCOPE NOTE
----------------------------------------
This model was trained on real Bangalore traffic rows for Silk Board Junction, Marathahalli Bridge, and Sarjapur Road only. It predicts Congestion Level from measured traffic volume, speed, capacity utilization, incident, public-transport, compliance, parking, pedestrian/cyclist, weather, roadwork, location, and date-derived features.
The selected Kaggle dataset does not contain ORR or Outer Ring Road rows. ORR congestion behavior in this project therefore remains simulation-based, calibrated against standard road capacity and the SUMO network, while the real-data model contributes evidence for the available Bangalore corridor locations. This is a hybrid real-data + simulation approach, not a claim that every route is directly real-data-driven.
